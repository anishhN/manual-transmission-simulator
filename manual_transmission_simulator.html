Model notes & assumptions

Read before using for reports
This is an educational formula-based prototype. Published Yanmar 2GM20F specifications anchor engine size and rated output; the selectable 5-speed gearbox is generic, not a Yanmar transmission. Intermediate torque-curve points, BSFC, thermal response, vibration amplitude and gear efficiency are modeled assumptions, not manufacturer test data. “Fuel heat input” is fuel mass flow × assumed diesel lower heating value; it is not a crank-angle-resolved in-cylinder heat-release-rate curve. Vibration is a heuristic trend indicator, while firing and gear-mesh frequencies are approximate indicators; neither is a measured spectrum. Gearbox output RPM uses selected gear ratio × final-drive ratio. For accurate heat-release rate, use cylinder-pressure vs crank-angle data and engine geometry; for validated vibration/temperature/fuel results, calibrate against dynamometer tests or connect sensors.
